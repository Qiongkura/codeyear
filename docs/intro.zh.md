# CodeYear · 中文简介

## 一句话

把本机 git 历史变成一份只属于你的年度代码手账。

## 仓库简介（GitHub About）

扫描本地 git 仓库，生成纸面档案风格的年度代码报告、高清海报和 GitHub 主页卡片。只读本地 git，不登录、不上传，私有项目也能用。

## 短简介

CodeYear 是一个本地优先的开发者年度报告工具。它直接读取你电脑上的 `.git`，只统计你本人的提交，生成纸面档案风格的 HTML 报告、2400×3200 海报、完整长图，以及可挂到 GitHub 主页的明暗双版本 SVG 卡片。没有账号、没有授权、没有网络请求。

## 长简介

官方的年度 Wrapped 通常只覆盖公开数据，还要授权；但大多数人的代码在私有仓库、公司内网或 Gitee。CodeYear 换了个思路：不联网，直接读本机的 git 历史。

它按 `user.name` / `user.email` 过滤出你本人的提交，按 commit hash 去重，并把同一项目的多个副本合并成一个。然后生成一份纸面档案风格的 HTML 报告：年度之最、仓库档案、全部仓库索引、月度节奏、7×24 提交时钟、全年热力图、语言构成、编码会话、仓库墓园等。除此之外还会输出一张 2400×3200 海报、一张完整长图，以及可挂到 GitHub Profile 的透明底 SVG 卡片。

整个工具只依赖 Python、Git 和 Pillow，没有前端构建步骤，也没有任何外部字体或 API 请求。

## 适合谁

- 想把一年提交记录做成年度总结的开发者
- 私有仓库多、不方便用在线 Wrapped 的人
- 需要离线或内网环境的人
- 想给 GitHub Profile 加一张数据卡片的人

## 亮点

- **只统计你本人**：默认按 git 身份过滤，`--all-authors` 可关闭
- **副本去重**：`work/`、`backup/`、fork 按项目血统合并，不重复计数
- **隐私优先**：零网络请求，数据不离开本机
- **多种输出**：HTML 报告、PNG 海报、长图、明暗双版本 SVG 卡片、JSON
- **中英双语**：同时生成中文和英文报告，页内可切换
- **中文优先**：系统字体、无外部依赖，报告和卡片都可直接分享
